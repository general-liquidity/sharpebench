\begin{abstract}
Benchmarks for AI trading agents rank on realized return over short windows, which measures the variance of noise more than skill: one widely cited board ranks on a Sharpe ratio whose confidence interval spans from $0.43$ to $2.59$. We describe SharpeBench, a deterministic, judge-free benchmark that ranks an agent only if its edge survives deflation for the number of strategies tried, reliability across every execution seed and out-of-sample window, a process audit that zeroes any entry earned by bypassing a risk control, and a block-bootstrap null. Raw return never ranks. We run it across nine frozen datasets spanning four asset classes and four bar sizes, from hourly crypto to weekly equity indices, and report three findings. First, the deflation prior the benchmark shipped with was annualized while the kernel computes Sharpe per period, so on daily bars an agent needed an annualized Sharpe of $18$ to rank and on hourly bars $106$; we correct the protocol and state it in checkable units. Second, with units corrected, no reference agent is eligible on any dataset, because every dataset contains a bear window and the reliability gate requires profitability in every window; this is the gate declining to certify that owning the index is safe in a downturn. Third, a weaker gate with a per-run drawdown bound refuses the same agents, which drew down between 32 and 67 percent in their worst windows. The luck floor of random agents never beats a reference agent, and with deflation switched off a random agent reaches a deflated Sharpe of $0.999$. The benchmark ships with a self-audit of eight attacks, a replay-recompute tamper check, golden fixtures checked on three operating systems, and a publicly verifiable signed board. Every number is produced by a listed command from committed data. External validation against live performance, and the competing agent that would show eligibility is attainable, are the outstanding experiments.
\end{abstract}
